# VHM — Tài liệu thiết kế kỹ thuật

## Cobroker

Đọc [TTD Cobroker](cobroker/ttd-cobroker.md): một tài liệu gồm nền tảng Cobroker và bốn tính năng:

1. Xếp hạng Sale theo doanh số.
2. Quản lý Sale cấm bán/hạn chế bán.
3. Theo dõi chu kỳ bán hàng, cảnh báo ngừng hợp tác.
4. Quản lý vùng, đại lý, liên minh và pháp nhân.

Tích hợp OCR/eKYC hiện hành sử dụng FPT qua service OCR/eKYC. Tài liệu có 16 mục theo mẫu L2 OCR/eKYC; trạng thái DRAFT, ghi rõ các điểm cần chốt và giới hạn kiểm chứng.
